# 🥊 FIGHT PICK — 격투 승부 예측

외부 패키지 없이 Node.js(18 이상)만 있으면 됩니다.

```bash
node server.js          # 기본 포트 3000
PORT=8080 node server.js
```

- 메인: `http://<컴퓨터IP>:3000` — 같은 와이파이의 휴대폰으로 접속
- 운영자: `http://<컴퓨터IP>:3000/admin`
- 타이머 전광판(프로젝터용): `http://<컴퓨터IP>:3000/?display`

관리자 비밀번호는 저장소에 평문으로 두지 않습니다(해시만 저장). 바꾸려면 `ADMIN_PASSWORD=새비번 node server.js`.

데이터는 `data/db.json`, 업로드 파일은 `data/uploads/`에 저장됩니다. 처음부터 다시 하려면 `data` 폴더를 지우세요.

## 규칙
- 가입: 닉네임 + 숫자 4자리 PIN → 100 응원 포인트 (현금 구매·환전·양도 없음, 활동 점수)
- 경기마다 1인 1표, 변경 불가
- 언더독: 실제 투표에서 지지율이 낮은 선수에게 표시, 투표 전에는 '집계 전'
- 결과 등록 시 적중 +20P, 언더독 적중이면 +30P 추가 (결과 취소 시 회수)
- 1라운드 시작 버튼을 누르면 투표가 자동 마감
